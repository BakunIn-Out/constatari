# Constatări

Aplicație web (PWA) pentru constatări pe teren: poze + dictare vocală, salvate pe telefon,
exportate la final ca fișier pentru „Combina backup-uri” din aplicația de verificări, plus raport PDF și CSV.

- Datele rămân pe telefon (IndexedDB) până la export. Nimic nu se trimite automat nicăieri.
- Listele (locații, etaje, apartamente, încăperi, firme) se importă din backup-ul aplicației de verificări (⚙️ Setări).
- Fără chei sau date în acest repository.
